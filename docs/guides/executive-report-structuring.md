# Structuring Executive Reports with Evidence Citations

## Overview
Analytical reports generated by AI systems must bridge the gap between rigorous quantitative computation
and clear executive decision-making. Athena enforces a structured report schema with strict citation
linkage between business recommendations and empirical evidence.

## Report Structure Architecture

```
┌────────────────────────────────────────────────────────┐
│                   Executive Report                     │
├────────────────────────────────────────────────────────┤
│ 1. Executive Summary (TLDR)                            │
│    - Plain language findings                           │
│    - Headline metric highlights                        │
├────────────────────────────────────────────────────────┤
│ 2. Empirical Findings                                  │
│    - Finding F1: Effect size, p-value, metric values   │
│    - Finding F2: Subgroup comparisons, confidence int  │
├────────────────────────────────────────────────────────┤
│ 3. Methodological Caveats                              │
│    - Sample size limitations, missingness, assumptions │
├────────────────────────────────────────────────────────┤
│ 4. Recommendations                                     │
│    - Actionable decision items                         │
│    - MUST cite supporting Finding IDs: ["F1", "F2"]    │
└────────────────────────────────────────────────────────┘
```

## Verifier Enforcement (Rule V4)
Athena's verifier enforces that every item in `recommendations` contains a non-empty `supporting_findings`
array citing valid finding IDs. Recommendations without direct empirical backing are rejected.
